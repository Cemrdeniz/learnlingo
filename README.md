# LEARN LINGO

This project is a modern and interactive web application developed for a company that provides online language learning services. Users can browse teachers, apply filters, manage favorite teachers, and book trial lessons.

## Features

- User registration, login, and logout using Firebase Authentication
- Teacher data management using Firebase Realtime Database
- Routing structure built with React Router (Home, Teachers, Favorites)
- Filtering teachers by language, student level, and hourly price
- Add / remove teachers from favorites with persistent storage
- Dynamic data loading with “Load More” functionality
- Modal windows with multiple close options (Esc key, backdrop click, close icon)
- Form validation using react-hook-form and Yup
- Fully responsive and semantic UI design

## Tech Stack

- Vite + React
- React Router
- react-hook-form
- Firebase (Authentication & Realtime Database)
- CSS Modules (in progress / planned)

## Pages

- **Home** — Showcases company benefits and navigation to the Teachers page  
- **Teachers** — Filterable and searchable teacher listing page
